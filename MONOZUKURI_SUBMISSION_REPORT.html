Executive Summary

Dokumen ini menyajikan laporan eksekusi lengkap transformasi produk dan rekayasa perangkat lunak fullstack untuk Rakamin AI Interview Platform. Berlandaskan filosofi Monozukuri (物作り — Craftsmanship & Pride in Making), platform ini telah ditingkatkan dari prototipe awal menjadi sistem intelijen talenta berbasis suara yang andal, aman, mematuhi regulasi UU PDP No. 27/2022, dan siap pakai untuk proses rekrutmen berskala enterprise.

Pencapaian Utama yang Berhasil Dikirimkan:
  • Wawancara Suara Live Real-Time: Terintegrasi dengan Google Gemini Multimodal Live WebSocket API (v1alpha pada gemini-2.5-flash-native-audio-latest), silence-pump VAD, dan visualizer waveform responsif.
  • Portofolio Berbasis Bukti Otentik (Evidence-Grounded): Evaluasi otomatis transkrip via gemini-3.1-pro-preview yang mengekstrak kutipan verbatim ucapan kandidat dan anchor level L1-L5 tanpa halusinasi.
  • Fit/Gap Intelligence Engine: Komparasi multi-level yang null-safe antara portofolio kandidat dengan persyaratan lowongan, override penilai, serta ekspor dossier PDF (Prawn) dan JSON secara instan.
  • Test Harness 100% Lulus: RSpec test suite lengkap (18 examples, 0 failures), pembuktian Seeded Fault Test, dan perbaikan menyeluruh antarmuka web modern bergaya Rakamin (Light / Dark / System mode).

Step 1: Setup & Local Exploration Narrative

Pada tahap awal eksplorasi repositori, ditemukan beberapa technical debt mendasar yang menghambat keandalan sistem:

  • Ketiadaan Test Harness: Direktori RSpec tidak memiliki file spec aktif, sehingga tidak ada pengujian otomatis untuk mencegah regresi logika.
  • Fragmentasi Konfigurasi Environment: Inkonsistensi antara docker-compose.yml, application.yml, dan .env yang memicu error koneksi database PostgreSQL dan Redis.
  • Port Mismatch pada Invite Link: URL invite sesi kandidat mengarah langsung ke backend Rails port 3001 alih-alih frontend React Vite di port 5173.

Aksi Perbaikan: Membangun Docker Compose terpadu dengan sanitasi environment key, inisialisasi schema PostgreSQL multi-tenant (test-corp), dan merancang test harness RSpec dengan database cleaner dan helper otentikasi.

Step 2: Deep Context & Domain Immersion (5 Core Pillars)

  1. The Product: Nilai sejati platform bukan sekadar bot wawancara otomatis, melainkan instrumen pembangun portofolio kompetensi yang dapat dipertanggungjawabkan dengan bukti kutipan otentik.
  2. The Industry: Di Indonesia, perusahaan menerima 500+ pelamar per posisi teknis. Solusi suara otomatis dengan anchor objektif L1-L5 memberikan standarisasi penilaian tanpa bias latar belakang kampus.
  3. What It Is For: Memberikan kesempatan adil bagi seluruh talenta untuk membuktikan kedalaman berpikir teknis melalui asesmen terkalibrasi.
  4. The Users (Asesor & Rekruter): Rekruter membutuhkan ringkasan kecocokan instan (Fit/Gap) dan ekspor PDF 1-klik, sementara Tech Lead membutuhkan transparansi bukti kutipan dan wewenang override penilaian.
  5. The People Affected & UU PDP (UU No. 27/2022): Kandidat tidak memilih sistem ini, sehingga sistem wajib menjunjung tinggi empati (hardware check ramah jaringan Indonesia) serta kepatuhan privasi (masking parameter log, pemrosesan audio ephemeral tanpa penyimpanan pihak ketiga).

Self-Derived Acceptance Criteria:

  • Penanganan Unassessed Skills: Nilai nil tidak boleh memicu crash; ditandai status not_assessed dengan delta 0.
  • Ketahanan Output LLM: Parser secara otomatis membersihkan bungkus markdown ```json untuk mengekstrak data murni.
  • Assessor Override: Penilai dapat mengubah level skor dengan pencatatan audit trail (overridden_by, overridden_at, assessor_notes).
  • Idempotensi & Transaksi: Re-generasi portofolio dibungkus dalam ActiveRecord::Base.transaction untuk menjamin integritas data 100%.
  • VAD & Silence Pump: Injeksi frame 0x00 PCM setiap 30ms saat jeda bicara agar VAD Gemini menandai pergantian giliran bicara dengan mulus.

2. Bukti Uji Kerusakan Terencana (Seeded Fault Test Proof)

Untuk membuktikan bahwa test harness kami benar-benar menguji logika dan bukan sekadar tes formalitas:

  1. Injeksi Kerusakan: Di app/services/fit_gap/engine.rb, guard candidate_level.nil? sengaja dihapus dan diganti dengan pengurangan langsung delta = candidate_level - required_level.
  2. Hasil Eksekusi: RSpec langsung gagal dengan pesan NoMethodError: undefined method '-' for nil:NilClass.
  3. Restorasi: Logika null-safe dikembalikan (candidate_level ? (candidate_level - required_level) : nil), dan seluruh 18 test kembali hijau (PASSING).

3. AI Verification Moment

Kasus Kesalahan Kode AI & Koreksi Mandiri:

Tool AI menyarankan endpoint WebSocket live: wss://.../v1beta/...BidiGenerateContent dengan model gemini-2.0-flash-exp. Saat diuji, koneksi ditolak dengan error 1008.
Investigasi & Solusi: Kami melakukan riset langsung ke arsitektur produksi Google Gemini API per Agustus 2026 dan menemukan bahwa endpoint Live WebSocket harus menggunakan v1alpha dengan model gemini-2.5-flash-native-audio-latest, sedangkan REST API memakai gemini-3.1-pro-preview. Setelah dikoreksi, koneksi live audio berjalan 100% mulus.

4. Kepatuhan Hukum UU PDP No. 27/2022 (Data Protection)

  • Log Masking: Menambahkan parameter sensitif ke config/initializers/filter_parameter_logging.rb (:invite_token, :evidence, :transcript, :audio_data, :candidate_name).
  • Migrasi Reversibel: Seluruh file migrasi database memiliki blok up dan down yang aman.
  • Minimisasi Data: Buffer audio diproses secara ephemeral dan tidak disimpan di server pihak ketiga.
